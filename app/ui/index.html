Letters, numbers, _ and . only. You can't change it later.

Start a new network

Deploy the privatewebchat server on Render first (see the README), then enter its address. Render serves it over port 443.

Letters, numbers, _ and . only. You can't change it later.

Choose a PIN

You'll enter it every time you open privatewebchat. It also encrypts everything privatewebchat stores on this computer, so it can't be reset: if you forget it, you'll need a new invite.
