## New
- **Invite codes you can say out loud**: 12 digits, like **4829 1300 7562**. Whoever gets one types the digits into the Invite code box instead of pasting a long code. Each works once and lasts 7 days.

## For the developer
- Make one in **Settings → Owner → Invite codes and owner commands → Make a code to say out loud**, or in Terminal with `node tools/owner.js spoken`. `node tools/owner.js spoken <code>` turns an invite code you already have into one.
