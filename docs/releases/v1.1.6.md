## New
- **Mentions**: type **@** and a name to ping someone. A list of people pops up as you type (Tab or Enter picks one). Whoever you mention gets a notification, even in General, and the message is highlighted for them.
- **Announcements**: a new channel under General for news from the developer and the patch notes for every update, like these. Only the developer can post there.
- **Opens when you log in**: privatewebchat now starts with your computer, so you don't miss messages. Turn it off in **Settings → Startup**.
- **Shorter invite codes**: new codes are about 120 characters instead of 1000. Older codes still work.

## Fixed
- **Notifications** now arrive reliably on Windows and Mac while privatewebchat is closed to the tray or menu bar, or behind other windows. On Mac they also show while privatewebchat is the active app, and clicking one opens privatewebchat. On Windows they show the privatewebchat icon. To check yours, use **Settings → Notifications → Send a test notification**.
- **Windows**: opening privatewebchat while it's already running now brings back the open window instead of starting another copy. Copies used to pile up in Task Manager and use up memory.
- **Mac**: opening a second copy of privatewebchat no longer asks to make it your default web browser. It brings back the window that's already open.
